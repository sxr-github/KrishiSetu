# contracts/

This directory stores **interface definitions** shared across the system:

- API contracts (e.g. OpenAPI documents, request/response shapes agreed between
  backend and clients)
- Smart-contract interfaces for the future blockchain audit/provenance layer

## Status

Empty in Phase 0 by design. No API contracts and no smart contracts are defined yet.

Blockchain contracts are **not** implemented in Phase 0 - see
[../PROJECT_STATUS.md](../PROJECT_STATUS.md).

Changing anything in this directory means changing a public contract, which requires
explicit agreement between both developers (see [../AI_RULES.md](../AI_RULES.md)).
